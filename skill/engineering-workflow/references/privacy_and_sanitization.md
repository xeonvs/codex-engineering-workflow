# Privacy And Sanitization

This skill is intended for public, reusable workflow scaffolding.

## Redaction Rules

- Do not copy private names, customer names, or user-specific identifiers.
- Do not copy secrets, bearer tokens, API keys, or internal hostnames.
- Do not include absolute local workstation paths in retained public docs.
- Do not transplant donor-repo prose verbatim.

## Safe Reuse

- generic file names
- generic section headings
- generic workflow patterns
- neutral validation and planning structures

## Before Finalizing

- scan outputs for deny-listed terms
- scan outputs for credential-like strings
- scan outputs for internal-only URLs or hostnames
- scan outputs for unresolved template placeholders
